# Raw Materials

Store original, unprocessed materials here. Each team member has an assigned research stream so that the evidence collection is complementary rather than duplicated.

## Team folders

- `01_Mod/` - scope, IT use case, and product requirements
- `02_My/` - heat-risk indicators and data sources
- `03_Belle/` - vulnerable population and dashboard data fields
- `04_Chris/` - dashboard UX, visualization, and accessibility
- `05_Com/` - stakeholders, contact points, and handoff channels
- `06_June/` - IT architecture, governance, evaluation, and Phase 0 feasibility

Examples:

- lecture notes and assignment instructions
- meeting notes copied directly from team discussions
- papers, reports, guideline links, and source PDFs
- screenshots, exported chats, or rough idea dumps

Rule: do not edit source meaning here. Keep files close to their original form so the team can trace every later decision back to the source.

## Source record minimum

For every source, record:

- title
- author or organization
- publication date
- URL, DOI, report number, or other identifier
- access date
- source type
- the member research question it supports
- file name saved in this folder

Do not add real patient-identifiable or confidential data.

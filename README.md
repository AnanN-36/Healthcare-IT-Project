# Healthcare-IT-Project

Repository for raw materials, processed notes, analysis matrices, and prototype-ready data for the Healthcare IT project.

## Project Workflow

Use the numbered folders as a research-to-prototype pipeline:

1. `00_raw_materials/` - original sources and meeting notes
2. `01_general_workflow/` - current-state and future-state workflow drafts
3. `02_analyzed_data_notebooklm/` - NotebookLM summaries and extracted insights
4. `03_matrices/` - comparison, scoring, stakeholder, risk, and requirement matrices
5. `04_production_inputs/` - cleaned data used for prototype or pitch production

See `docs/project-workflow.md` for the full working process.

# Production Inputs

Store cleaned, prototype-ready data here.

Examples:

- mock cases
- JSON or CSV data for the prototype
- finalized decision rules
- cleaned workflow steps
- selected references for final slides
- demo scenarios

Rule: only put data here after it has been checked against the workflow and matrices.

For this project, the first production inputs should be limited to the Heat Risk Dashboard:

- dashboard field specification
- illustrative heat-risk mock data
- information hierarchy or wireframe requirements
- contact-point and handoff content for the five supporting components
- one or more demo scenarios
- Phase 0 roadmap and evaluation measures

Do not place clinical treatment rules, real personal data, or unverified alert thresholds here.
